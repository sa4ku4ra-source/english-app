# My English Notebook

AIと普段どおり会話しながら、自分が「これ英語でなんて言う？」と聞いた表現だけを貯めていく英会話アプリです。最初から用意された教材はありません。

## できること

| 画面 | 内容 |
|---|---|
| 💬 会話 | 英語でも日本語でも普段どおり話しかけると、AIはずっと英語で返事（自動で読み上げ） |
| 📌 ストック | 自分が聞いた表現が貯まる。再生・ゆっくり・3回リピート・発音チェック |
| ⚙️ 設定 | APIキー、AIモデル、声・スピード・アクセント、バックアップ |

### ストックの増え方
- 会話中に「これ英語でなんて言う？」と聞くと、ネイティブの言い方を1つ答えてくれて、それがストックされます
- 「他の言い方ある？」と聞くと、別の表現が1つ、同じストックに追加されます
- AIが勝手に例文や教材を作ることはありません

### 耳で覚える
- 最初は英文と音だけ。説明やカタカナは出しません
- わからない単語は**長押し**すると、意味と実際の音のつながり方を調べられます（その文をストックすることも可能）
- 発音チェック：英文を声に出すと音声認識で聞き取り、伝わらなかった単語を赤で表示

### 話し方
- 🎤 を押したら、話し終えて**もう一度押すまで**聞き続けます。長い文でも普段の速さでOK
- 話している途中でも 🇺🇸/🇯🇵 ボタンで英語⇄日本語を切り替えられます。英語で言えなかった部分はAIが自然な英語で言い直し、ストックされます
- 会話中は間違いを指摘しません。「会話を終了」を押すと、不自然だった表現や日本語で言った部分の英語をまとめて教えてくれます

## 使い方

### 1. Anthropic APIキーを用意
<https://console.anthropic.com/> でAPIキーを作成し、アプリの「⚙️ 設定」に貼り付けます。
キーはその端末のブラウザ内（localStorage）にだけ保存されます。

### 2. アプリを開く
マイクを使うため **https か localhost** で開く必要があります（ファイルを直接ダブルクリックだとマイクが使えません）。

**おすすめ：GitHub Pages で公開（スマホからも使える）**
1. GitHubのリポジトリ画面 → Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main`・`/ (root)` に設定して Save
3. 数分後に `https://sa4ku4ra-source.github.io/english-app/` で開けます
4. スマホではホーム画面に追加しておくとアプリのように使えます

**パソコンで試すだけなら**
```
cd english-app  # このリポジトリのフォルダ
python3 -m http.server 8000
```
→ ブラウザで <http://localhost:8000> を開く

### 推奨ブラウザ
- パソコン：Chrome / Edge
- iPhone：Safari　／　Android：Chrome

読み上げの声は端末に入っている音声を使います。設定画面で一番自然に聞こえる声を選んでください
（iPhoneは「設定 → アクセシビリティ → 読み上げコンテンツ → 声」で高品質な英語音声を追加すると、さらに自然になります）。

## データについて
- ストックと会話はブラウザ内に保存されます。端末やブラウザを変えると引き継がれないので、ときどき「設定 → 書き出し」でバックアップしてください（別の端末で「読み込み」すれば移せます）
- AIとのやり取りは Anthropic API に直接送られます

## ファイル構成
- `index.html` — 画面
- `style.css` — デザイン（ダークモード対応）
- `app.js` — 会話・ストック・長押し検索・再生・発音チェック・フィードバックの処理
