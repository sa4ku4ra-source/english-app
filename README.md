# My English Notebook

自分が普段話している日本語を、ネイティブが実際に使う英語にして「自分だけの教材」として積み上げていく英会話アプリです。

## できること

| 画面 | 内容 |
|---|---|
| ＋ 追加 | 日本語を入力（または日本語で話す）→ ネイティブが実際に言う英語に変換して教材に保存 |
| 📚 教材 | 保存した文を何度でも再生。ゆっくり再生・3回リピート（真似する間つき）・発音チェック |
| 💬 会話 | 選んだ教材の文を使う場面をAIが作って英語で会話。AIの返事は自動で読み上げ |
| ⚙️ 設定 | APIキー、AIモデル、声・スピード・アクセント、教材のバックアップ |

### 発音重視のしくみ
- 各フレーズに **「実際の聞こえ方」**（リンキング・弱形・強く読む所を大文字で表示）とカタカナ表記
- その文に特有の **発音のコツ**（フラップT、音の脱落、イントネーションなど）
- **発音チェック**：英文を声に出すと音声認識で聞き取り、伝わらなかった単語を赤で表示して点数化

### 会話のルール
- AIはずっと英語のまま。こちらが日本語で話しても（「🎤 日本語」ボタンや日本語入力）英語で会話を続けます
- 会話中は間違いを指摘しません。**「会話を終了」を押すと、不自然だった表現・文法ミス・日本語で言った部分の英語** をまとめて教えてくれます
- 直された表現は「＋ 教材に追加」ボタンでそのまま教材になります

## 使い方

### 1. Anthropic APIキーを用意
<https://console.anthropic.com/> でAPIキーを作成し、アプリの「⚙️ 設定」に貼り付けます。
キーはその端末のブラウザ内（localStorage）にだけ保存されます。

### 2. アプリを開く
マイクを使うため **https か localhost** で開く必要があります（ファイルを直接ダブルクリックだとマイクが使えません）。

**おすすめ：GitHub Pages で公開（スマホからも使える）**
1. GitHubのリポジトリ画面 → Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main`・`/ (root)` に設定して Save
3. 数分後に `https://sa4ku4ra-source.github.io/english-app/` で開けます
4. スマホではホーム画面に追加しておくとアプリのように使えます

**パソコンで試すだけなら**
```
cd english-app  # このリポジトリのフォルダ
python3 -m http.server 8000
```
→ ブラウザで <http://localhost:8000> を開く

### 推奨ブラウザ
- パソコン：Chrome / Edge
- iPhone：Safari　／　Android：Chrome

読み上げの声は端末に入っている音声を使います。設定画面で一番自然に聞こえる声を選んでください
（iPhoneは「設定 → アクセシビリティ → 読み上げコンテンツ → 声」で高品質な英語音声を追加すると、さらに自然になります）。

## データについて
- 教材はブラウザ内に保存されます。端末やブラウザを変えると引き継がれないので、ときどき「設定 → 書き出し」でバックアップしてください（別の端末で「読み込み」すれば移せます）
- AIとのやり取りは Anthropic API に直接送られます

## ファイル構成
- `index.html` — 画面
- `style.css` — デザイン（ダークモード対応）
- `app.js` — 翻訳・再生・発音チェック・会話・フィードバックの処理
